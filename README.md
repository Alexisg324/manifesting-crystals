# Manifesting Crystals

Website for Manifesting Crystals (@manifesting.with.crystals): crystal grids, crystal basics and the book *Manifesting With Crystals*.

Plain HTML and CSS, published with GitHub Pages from the `main` branch.

- `index.html`: home
- `grids.html`: crystal grids
- `learn.html`: chakras, how to use a grid, what manifesting is
- `book.html`: the book (coming soon)
- `style.css`: brand kit colors and fonts
